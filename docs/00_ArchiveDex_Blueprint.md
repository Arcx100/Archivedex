# ArchiveDex Blueprint

ArchiveDex is a premium discovery archive for Pokémon ROM hacks, fangames, PMD hacks, side games, and preservation-worthy fan projects.

## Main goal

Help users find what to play, collect, compare, or skip.

## Core focus

1. Discovery
2. Curation
3. Game identity
4. Visual presentation
5. Comparison
6. Preservation
7. Source trust as metadata

## MVP pages

- Home
- Library/Search
- Game Detail
- Collections
- Source Notes

## MVP build rule

Use 10–20 test games first. Make the system good before importing the full 500+ archive.
