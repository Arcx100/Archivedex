## How to Use This Collection

### For New Players
Start with **[[#S-Tier Must-Play]]** entries. Pokemon Unbound, Gaia, or Glazed are perfect starting points. If you want something familiar but better, try Emerald Legacy or Inclement Emerald.

### For Challenge Seekers
Jump to **[[#Difficulty Hacks & Kaizo]]**. Radical Red and Emerald Kaizo are the gold standards. Start with Inclement Emerald's Hard mode or Emerald Horizons before tackling Kaizo.

### For Collectors
Browse **[[#Collection Worthy]]** for historical curiosities, bootleg-adjacent titles, and early hacking experiments. Pokemon Brown, Prism, and Shiny Gold are essential pieces of hacking history.

### For Completionists
Use the **[[#Quick Reference Tables]]** to filter by playtime, dex size, or difficulty. The `Tags` system allows for quick filtering in Obsidian.
